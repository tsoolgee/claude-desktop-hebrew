# claude-desktop-hebrew

ממשק בעברית ל-Claude Desktop (Windows), כולל היפוך לכיוון RTL.

הממשק מתורגם עבור כ-34 אלף מחרוזות. מחרוזת שאין לה תרגום נשארת באנגלית.

## איך זה עובד
- ממשק האפליקציה הוא אתר מקומי ב-`resources\ion-dist`, מחוץ ל-`app.asar`, לכן אין צורך לשנות את ה-EXE או את בדיקות השלמות שלו.
- `patcher/hebrew_patch.py`:
  - מוסיף `he-IL` לרשימות השפות של האפליקציה (נמצאות לפי תוכן, לא לפי שם קובץ, כדי לשרוד שמות מגובבים בגרסאות חדשות);
  - יוצר `i18n/he-IL.json` ו-`i18n/dynamic/he-IL.json` מתוך `translations/he.json` (אנגלית ← עברית, לפי טקסט ולא לפי מפתח, כדי לשרוד עדכוני גרסה);
  - מזריק `assets/he-rtl.js` שהופך את הדף ל-RTL כשהשפה היא עברית.
- ההתקנה של Claude נמצאת תחת `WindowsApps`, ולכן הכלי לוקח בעלות על התיקייה ומבקש הרשאות מנהל.

## שימוש
```
python patcher/hebrew_patch.py            # מתקין (מבקש הרשאות מנהל)
python patcher/hebrew_patch.py --revert   # מחזיר את המקור
```
אחרי ההתקנה: מפעילים מחדש את Claude, ובהגדרות ← שפה בוחרים עברית.

**אחרי כל עדכון של Claude צריך להריץ שוב.**

## בדיקות
`tools/spa_serve.py` מגיש עותק מתוקן בדפדפן רגיל לבדיקה מהירה. שימו לב: שרת הבדיקה צריך להחזיר `{}` לקבצי `dynamic` חסרים, כמו שהאפליקציה עושה.

## פיתוח
- `tools/validate.py` מנתח הודעות ICU (כולל `plural`/`select`) ובודק שתרגום שומר על המשתנים והתגיות.
- `tools/merge.py` ממזג את תוצרי התרגום ל-`translations/he.json`.
- `tools/TRANSLATE_PROMPT.md` ו-`translations/GLOSSARY.md` הם ההנחיות והמילון שהתרגום בוצע לפיהם.

## הערה
התרגום נעשה על ידי מודל שפה ולא עבר הגהה אנושית. תיקונים ב-`translations/he.json` יתקבלו בברכה.
